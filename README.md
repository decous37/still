# Still

[简体中文](./README.md) | [English](./README.en.md)

Still 是一个适合碎片时间的注意力训练小网站。打开页面，从眼前的几个字开始：看清顺序、点选字块，或读完一句话，再补回藏起来的词。

每组十题，没有倒计时、排名或解锁要求。页面以文字为中心，使用浅色透光与深色玻璃两套外观，声音和触感都可以关闭。

## 怎么玩

刷新或重新打开页面，会从当前语言的「重组」第一组第一题开始。

| 模式 | 玩法 |
| --- | --- |
| 重组 | 对照完整词语，从左到右点选字符，逐字填绿 |
| 句子 | 对照句子底稿，按显示顺序点选词块 |
| 补回 | 先读再隐藏，按顺序补回词语；短题一空三选一，中长题两空共用四个候选 |

选对的部分会变绿；选错时，整条文字短暂变红，随后重置本题。完成后自动进入下一题。相同的字可以使用任意一个尚未选过的对应字块。

两空题须从左到右作答；第二空选错也会重置两空，不重新展示答案。「再读一遍」会清空本次填写，重新展示原句。

补回题也可以按空格键隐藏或显示词语，不受「轻键」开关影响。重新显示会清空本次填写；暂停、集合和换题期间不会切换。

顶栏的「集合」可以浏览模式、题组和题目。打开集合或偏好页时，练习暂时冻结；切到后台后，返回页面需要点击「继续」。

普通输入使用轻薄键击音，整题完成是金属轻碰短响，错误是一声电子短滴。静音统一关闭三种声音，触感单独设置。浏览器不支持声音或震动时，仍可正常练习。

## 轻键

桌面上可以直接按键选词，不必来回移动鼠标。在「偏好」中打开或关闭「轻键」；支持悬停和精细指针的设备默认开启，手动选择会保存在本机。

候选按显示顺序对应 `asdfghjkl`，超过九项后接 `qwertyuiop`。每个词块内部右上角会显示对应字母。选过的词仍占原位置，再按它的键不会有反应或声音；鼠标和触控仍可用。

请使用英文输入状态。快捷键按实际字母识别，兼容大小写，不响应长按重复、输入法组合输入或 Ctrl／Command／Alt 组合键。集合、偏好、暂停、换题及补回原句阅读期间不响应选词。Tab、Enter 和空格保留原有操作；藏词、再读和继续没有额外字母快捷键。最多映射19项，超出的候选仍可点击或用 Tab 选择。

## 题库与进度

当前共有 **600 题**：中文和英文各 300 题，每种语言包含三个模式，每个模式十组，每组十题。

每组第1题为短题、第9题为长题，其余8题为中等题。全库480题（80%）为中等长度，短题和长题各60题。

| 内容 | 短 | 中等 | 长 |
| --- | --- | --- | --- |
| 中文重组 | 3–5字 | 6–7字 | 8–10字 |
| 英文重组 | 4–6字母 | 7–9字母 | 10–12字母 |
| 中文句子、补回 | 10–15字 | 16–24字 | 25–32字 |
| 英文句子、补回 | 6–8词 | 9–13词 | 14–18词 |
| 句子词块 | 3–4块 | 5–6块 | 7–8块 |

中文长度不计标点与空格；英文缩写、带连字符的词算一个词。英文重组全部小写，句子保留符合语法的大写。

十个主题为：居家、自然、光影、天气、植物、饮食、阅读、出行、物件、声音。中英文采用相同主题，题目不要求逐句对应。

- 题号表示当前在组内的位置，进度光带表示本组已经完成的不同题目数。
- 集合中的数字是该题在当前题库版本的完成次数，未完成显示 `0`。
- 重复完成同一道题会增加历史次数，但不会重复增加组进度。
- 做到第十题便进入组末页。从中途选题开始，也可能在进度未满时到达组末。
- 「再练本组」清空当前语言、当前组的进度，不清除历史次数。「下一组」保留下一组已有的进度。

## 本地运行

需要 Node.js **22.13 或更新版本**及 npm。在包含 `package.json` 的 `still` 目录中运行：

```sh
npm ci
npm run dev
```

打开终端给出的本地地址，通常为 `http://localhost:3000`。基本练习不需要账户、API 密钥或数据库。

常用命令：

| 命令 | 用途 |
| --- | --- |
| `npm run dev` | 启动开发服务 |
| `npx tsc --noEmit` | 检查 TypeScript 类型 |
| `npx vitest run` | 运行自动化测试 |
| `npm run lint` | 检查代码规范 |
| `npm run format` | 格式化代码，会修改文件 |
| `npm run build` | 生成生产构建 |
| `npm start` | 用 Wrangler 本地运行构建产物，需先构建 |

`npm start` 不会发布网站，访问地址以终端输出为准。

## 技术与目录

界面使用 React 19、TypeScript、Vinext / Vite 和 Tailwind CSS 4。抽屉等控件沿用 Base UI 组件体系，音效由 Web Audio 在浏览器中合成。练习判定与进度管理在客户端完成，当前没有账户系统、业务后端或排行榜。

| 文件 | 职责 |

| `app/page.tsx`、`app/layout.tsx` | 页面入口、元信息与首屏语言、主题设置 |
| `components/still/air-app.tsx` | 导航、偏好、组末页面、完成次数与进度协调 |
| `components/still/live-practice.tsx` | 练习交互、后台暂停和自动换题 |
| `components/still/engine.ts` | 输入判定与练习状态转换 |
| `components/still/draft-text.tsx`、`candidate-words.tsx` | 底稿与候选字块 |
| `components/still/collection-drawer.tsx` | 集合抽屉、题组浏览和选题 |
| `components/still/questions.ts` | 题目接口、长度标准、分组取题与展示清理 |
| `components/still/group-content.ts` | 600题内容，使用显式ID保持原有组内顺序 |
| `components/still/group-progress.ts` | v2完成次数读取、组进度保存与去重 |

## 数据保存

语言、主题、声音、触感、逐题完成次数和组进度保存在当前浏览器的 `localStorage` 中。中英文的组进度相互独立；刷新保留记录，但不恢复正在作答的位置。

本次题库改写启用 `still:question-completions:v2` 和 `still:group-progress:v2`，练习记录从零开始。原 `v1` 次数、进度和迁移标记仍保留在浏览器中作为旧版备份，不导入新版，也没有自动恢复入口。语言、主题、声音和触感设置不重置。

没有跨设备同步。更换浏览器、访问地址或清除站点数据后，原记录可能不可用。存储被禁用时，练习仍可进行，但记录无法保证在下次打开时保留。

## 修改题目

全部题目集中在 `group-content.ts`，每行以显式题目ID开头，用 `~` 分隔内容。重组写完整词语，句子用 `|` 拆分词块，补回用 `[词语]` 标出空位，末尾用 `|` 分隔两个干扰词。英文空格属于原句内容，不能随意裁掉。

`questions.ts` 将内容转换为题目对象，附加 `lengthTier`；补回使用有序的文本片段和空位 `segments`，从同一结构生成阅读、隐藏及完成题面。组内第1、9题的位置分别决定短、长档位。

维护时请保留已有题目和题组 ID，它们关联用户的本地记录。每种语言、每个模式保持十组，每组十题，避免题目遗漏或重复归组。

句子模式的展示与判定均采用 `answers[0]`，不接受与底稿不同的语序。补回短题一个答案，中长题两个不同答案，均配两个不同干扰词；句末标点由统一函数清理。英文大小写直接写对，不靠样式修正。

修改后运行 `npx vitest run`。现有测试覆盖题库数量、分组完整性、规范化重复文本、答案可完成性、重复字符、双空错误重置、v1/v2记录隔离和音源取消等。自动检查不能代替中英文内容复核。

## 使用与验证边界

Still 提供观察、顺序处理和短时回忆练习。它是否能改善日常阅读、工作中的注意力，尚未经过研究验证；游戏完成次数或正确率不能证明训练效果。本项目不提供注意力障碍的诊断或治疗。

键盘操作、读屏提示和减少动态效果已有实现，但完整读屏流程、200% 放大、Safari 与手机音效和触感仍需实机验证。鼠标卡顿或漂移的根因尚未确认，不能视为已经修复。

# Still 题库审核清单

更新：2026-09-09。

## 范围

本轮将当前活动题库扩展到中英文合计 204 题：每种语言 102 题，每种语言下 `word`、`sentence`、`recall` 三种模式各 34 题。

旧题 ID `0` 至 `11` 保持不变；新增题使用同一命名空间内的 `12` 至 `33`。运行时题目身份来自显式 `id` 字段，不再由 `Array.from({ length: 12 })` 生成。网页练习集已接入三个单模式入口，每个入口进入当前语言对应模式的 34 题；首页默认进入“整理一句话”。

## 自动结构审核

已由 `components/still/engine.test.ts` 覆盖：

- 每种语言、每种模式各 34 题。
- 全库 204 个题目 ID 不重复，且匹配语言与模式。
- 每题块 ID 不重复。
- 每个可接受答案都能由该题字块或词块组成，重复字块按可用数量计算。
- 完整单模式练习集为 34 题。
- `sentence` 模式导出到页面的题面、词块和答案末尾不带句号。
- 既有中文替代语序 `今天 我 在家看书。` / `我 今天 在家看书。` 仍可按前缀接受。

## 人工内容审核口径

已做作者自查：

- 英文重组题以 4 至 7 字母常见词为主。
- 中文重组题为自然 2 至 5 字短语。
- 排序题保持 3 至 5 个词块，优先使用单一自然语序；已知可接受替代语序保留在 `answers`。
- 阅读补回为短句，干扰项保持词性和长度接近。
- 内容围绕日常物品、自然观察、轻微动作与生活片段，减少重复的放松指令。

尚未完成：

- 未做真人试用。
- 未做独立第二人逐题文案复核。
- 未验证真实手机上的阅读与触感体验。

## 复核建议

下一轮人工复核时优先抽查：

- 英文阅读补回里干扰项是否过于显眼。
- 中文排序题是否存在未登记但自然的替代语序。
- 含重复文字的中文重组题是否在触屏上容易误判为系统问题。
- 题目列表中相邻题是否有语义过于接近的连续内容。

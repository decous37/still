# 幻彩 / Prism：本地原型交接

本版为幻彩首版原型。按最新要求，源码及文档提交至GitHub，并以 `VITE_PRISM_ENABLED=true` 构建更新现有公开站点；普通练习保持原有行为。仓库包含默认关闭的 `.env.example`；本机 `.env.development.local` 不上传。后续构建必须显式设置该变量才能保留幻彩入口，不能仅修改运行时变量。公开更新不代表下方列出的真机、听感与长期性能验证已完成。

## 开发与功能开关

- 保持原有 `npm run dev`、`npx tsc --noEmit`、`npx vitest run`、`npm run build` 流程，不新增依赖。
- `VITE_PRISM_ENABLED` 只有字符串 `true` 开启；默认关闭。开发覆盖放入被忽略的 `.env.development.local`，生产需要在构建环境显式设置。修改后重启或重新构建，不是远程开关。
- `#prism` 为客户端独立视图。刷新仍回普通首页；关闭配置时该地址回普通练习。
- `air-app.tsx` 仅接入口、懒加载和离开拦截。普通练习保持挂载并冻结，不修改普通题目接口、计数与进度。

## 玩法与资源生命周期

- 独立 `Session` 管理准备／运行／暂停／结束、正确前缀、120ms换题锁定、分数、有效选择数、连击、完成题数和有效时间。
- 错误为非阻塞局部反馈，不清空前缀；错误断连击但不扣分。已用、非法或锁定期间输入无效，不计正确率。每个正确选项10分；完成不另加分。
- 计时使用 `performance.now()` 差值并扣除暂停。200ms更新仅发生在时钟子组件，Canvas不依赖React逐帧渲染。
- 题库用不重复袋抽取，跨袋不立即重复，同题型不连续超过3题。候选在发题时打乱，本题内不重新分配键位。
- 键盘使用现有字母映射过滤，额外追踪按下／释放状态；忽略长按和双击第二击。错误提示不会阻塞下次输入。
- 设置、后台、失焦、离开确认暂停计时和音画；返回主动继续。离开取消后保持暂停。刷新／关闭标签页使用原生离开提醒，仍不保存本局。
- 所有幻彩偏好写入 `still:prism:preferences:v1`，验证音量范围，存储异常退回会话。普通偏好键不变。
- 音乐使用AudioContext时钟，25ms调度器预排100ms，16小节循环，每4小节变化。调度延迟跳过错过节拍，不补播。最大24声部，主增益限制、压缩器、短淡入淡出。
- 正确／错误／完成短音独立于音乐音量。异步音频恢复使用代次校验，暂停或卸载后不启动延迟音乐；退出取消调度、关闭音频上下文。
- Canvas粒子上限桌面120／窄屏40，DPR≤1.5，卸载取消动画帧与ResizeObserver；界面节拍亮度跟随音频时钟，无音频则视觉自计时。
- 低动态或系统减少动态效果关闭持续运动与按键位移，仅保留静态色彩和局部状态；没有全屏频闪。Canvas不接收点击或进入读屏树。

## 24题内容审核

- 每语言12题，重组6题／句子6题；每类1短、4中、1长，沿用普通模式对应长度与词块标准。
- 采用独立 `prism-v1-*` ID；没有借用普通题目的完成记录。
- 作者逐条检查：行动、舞台、探索与突破主题，中文自然短语、英文正常大小写，不引用歌词或既有广告口号。尚未经过独立编辑复核。
- 自动检查唯一内容、长度、分块数量、候选上限、英文大小写与答案可完成性。测试连续完成每语言60题、跨5袋，检查题序限制与计分。

## 验证与限制

- 已验证：中文浏览器26题、英文浏览器36题（均使用键盘及鼠标，包含第10项后的上排键）；均跨袋并连续换题。
- 已验证：错误保留前缀并立即修正、设置暂停不累计时间、关闭设置后保持暂停、低动态与静音开关、离开确认、结束数据、重开归零。
- 自动测试覆盖题库、序列、计分、锁定、计时、键释放、偏好降级及音频调度取消／声部上限／延迟恢复取消／无音频降级。
- 本地浏览器单局连续运行11分14秒，完成36道英文题；末尾按键仍正常计分，未捕获到控制台错误或警告。320px、380px及1440px布局DOM检查无横向溢出，窄屏候选命中区域超过44px；粒子保持在对应上限内。原生截图在大尺寸覆盖时存在捕获异常，桌面完整视觉还需人工复核。
- 37项测试、类型检查、差异空白检查通过；幻彩开启和关闭两种生产构建均通过。本次发布构建显式开启幻彩，开发环境继续开启。
- 普通模式回归实测：进出幻彩保留部分输入；集合仍正常选题；双空补回可用空格隐藏与再读。试跑后恢复中文首页和默认浏览器尺寸。
- 持续运行不等于已完成帧率／堆内存剖析、30分钟性能测试或实际听感审核；声音资源上限与取消通过自动化验证，尚未主观确认长期播放是否疲劳。
- 仍待公开上线前验证：真实手机触控和Safari、输入法、读屏、200%缩放、音量与长期听感、30分钟性能、禁用音频／存储的完整浏览器流程及小范围真人试用。
- 本版没有埋点、账户、后端、排名、自适应难度或训练效果宣称。先收集试用反馈，再决定是否扩至每语言60题。
